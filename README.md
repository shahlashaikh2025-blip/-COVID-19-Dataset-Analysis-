# COVID 19 Dataset Analysis

This project performs Exploratory Data Analysis (EDA) on a COVID-19 patient-level dataset.

## 📊 Project Overview
The objective of this project is to analyze patient demographics, ICU admissions, and mortality patterns using Python.

## 🔍 Key Analysis Performed
- Data Cleaning & Preprocessing
- Age Distribution Analysis
- Death Analysis
- ICU Admission Analysis
- Correlation Heatmap

## 🛠 Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 📁 Dataset
Covid Data.csv (Kaggle Public Dataset)
